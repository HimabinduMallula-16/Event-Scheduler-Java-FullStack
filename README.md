# Event Scheduler - Java Full Stack Project

A responsive Event Scheduler web application developed using Java Full Stack technologies for managing and organizing events efficiently.

---

## Features

- User Registration and Login
- Session Handling
- Add Event
- View Events
- Update Event
- Delete Event
- Event Status Management
- Event Priority Management
- Responsive Bootstrap UI
- JDBC Connectivity
- MySQL Database Integration

---

### Frontend
